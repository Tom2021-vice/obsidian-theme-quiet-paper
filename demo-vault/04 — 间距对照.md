# 间距对照

这页用于比较阅读视图和实时预览。先把光标移到文末看整体，再点击标题后的空行、代码和表格，检查编辑状态。

## 标题接子标题
### 没有空行的子标题
- 第一项说明，与上一行标题直接相邻。
- 第二项说明，列表项之间保持紧凑。
- 较长的第三项会在窄列里折行，用来检查项内行距与项间留白的区别。

## 标题与列表之间有空行

- 第一项说明。
- 第二项说明。

## 标题直接接正文
正文与标题之间由主题提供间距，不必为了外观再多插入一个空行。

这是下一段，检查段间空行。

## 正文与代码块之间没有空行
准备一个消息：
```javascript
const message = 'Spacing sample';
```
显示消息：
```javascript
console.log(message);
```
代码块之后也需要有可辨认的留白。

## 正文与代码块之间有空行

准备另一个消息：

```javascript
const anotherMessage = 'With source blank lines';
```

这是代码块后的一段正文。

## 标题后保留空行的表格

| 项目 | 内容 |
| --- | --- |
| 正文字体 | 由主题搭配 |
| 代码中的空行 | 不压缩 |

## 标题直接接表格的解析对照
| 项目 | 内容 |
| --- | --- |
| 检查方式 | 观察当前 Obsidian 是否正常识别 |
| 说明 | 主题只调整显示，不修改 Markdown 解析 |

## 代码内部空行

```javascript
const first = 1;

const second = 2;
```

代码内部的空行应保持完整高度。点击任意段间空行后，编辑中的空行也应恢复正常行高；在该行输入中文、选中、删除与撤销。

光标可以先放在这一行。
