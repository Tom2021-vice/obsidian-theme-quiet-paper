## Mermaid 打印边界

下面的长横向图用于检查打印时右侧的终点是否完整。打印应等比缩放，而不是截掉节点；文字较小时，可选择横向纸张。

```mermaid
flowchart LR
    A[记录需求] --> B[编写 Markdown]
    B --> C[在 Obsidian 中预览]
    C --> D[检查 Quiet Paper 排版]
    D --> E{检查是否通过}
    E -->|需要调整| F[修正字体与留白]
    F --> G[重新检查长链接和图表]
    E -->|通过| H[导出 PDF]
    G --> H
    H --> I[确认末尾节点完整]
```

下面的纵向图用于检查高度约束；图表应整体放入页内，不将底部节点裁掉。

```mermaid
flowchart TD
    A[开始] --> B[整理输入]
    B --> C[阅读文档]
    C --> D[记录问题]
    D --> E[拟定方案]
    E --> F[制作样例]
    F --> G[检查结果]
    G --> H[修正细节]
    H --> I[准备输出]
    I --> J[打印检查]
    J --> K[保存记录]
    K --> L[结束]
```
