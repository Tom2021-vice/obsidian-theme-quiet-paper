## TeX Gyre Pagella

The four embedded font faces are based on TeX Gyre Pagella, distributed under the **GUST Font License**, which refers to the LaTeX Project Public License 1.3c or later.

- Upstream project and authorship: https://www.gust.org.pl/projects/e-foundry/tex-gyre/pagella
- Complete upstream distribution: https://ctan.org/pkg/tex-gyre
- Original OpenType files: https://mirrors.ibiblio.org/CTAN/fonts/tex-gyre/opentype/
- Local changes: OpenType files converted to WOFF2 using fontTools, without subsetting or intentional glyph changes. The CSS family name `Quiet Pagella` is a local alias, not a claim to authorship of the font.
- Detailed file manifest: `assets/fonts/README.md` in source; `licenses/FONT-NOTICE.md` in install packages.
- License texts: `assets/fonts/GUST-FONT-LICENSE.txt` and `assets/fonts/LPPL-1.3c.txt` in source; the corresponding files in `licenses/` in install packages.

Font defects introduced by this conversion should be reported to this theme's maintainers; no support from upstream authors is implied.
