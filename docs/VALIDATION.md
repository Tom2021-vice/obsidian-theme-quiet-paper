## 0.1.3 本轮调整与检查

按用户五张参考截图，调整引用、行内代码、左侧文件管理器和顶部文档标签。项目已移动至 `D:/My project/Github/Obsidian_Theme`，继续沿用原有 Git 历史。

- 引用竖线从 2px 增至 4px，浅深色分别配置背景与文字颜色，多行实时预览引用仅在首尾增加较大内边距，保留原生缩进和编辑标记。
- 行内代码使用独立琥珀色调与细边框，通过局部变量让原生反引号编辑样式继续连接各段；不改围栏代码配色与表格换行。
- 文件管理器采用八组低饱和配色，只按顶层文件夹计数；后代继承颜色。原生展开控件仍保留，新增装饰图标不接受鼠标事件。普通目录、活动项、聚焦与拖动反馈分别检查。
- 普通桌面标签通过原生变量调整圆角、底部转角和轮廓。没有重新绘制按钮或替换原生交互。[变量依据：Obsidian Tabs](https://docs.obsidian.md/Reference/CSS%20variables/Components/Tabs)

`npm run check` 通过；`npm run test:appearance` 浅深色合计 72 项静态检查通过，覆盖引用与代码配色、文字对比度、目录颜色继承、图标开合状态、选中与焦点样式、设置退出和标签范围；`npm run test:spacing` 原有 42 项检查通过。

检查过程中加深了浅色目录颜色，使常态文字与分组背景对比度均达到 4.5:1；修复了装饰图标选择器优先级导致文件夹显示为文件图标的问题，并补上开合图标检查。已查看浅深色静态样张。样张只用于独立 CSS 复核，不是运行 Obsidian 的截图。

仍待用户实机验证：引用连续编辑和嵌套、反引号与表格单元格编辑、目录展开收起/重命名/拖动/键盘焦点、标签拖动/关闭/叠放、第三方图标插件兼容。Style Settings 新选项面板仍未实测。本轮未启动、关闭、连接或控制 Obsidian，也未修改个人库。


## 用户截图反馈与本轮修改

用户已提供首版长截图及普通窗口截图，并确认清空正文字体设置。截图可以确认衬线观感和纸面外观已生效，不能仅凭截图确认具体字体文件及完整双视图一致性。长图在聊天中缩小后显得字小，不据此修改字号。

长表格中的代码路径挤占文字列宽，导致“功能”列频繁换行。0.1.1 增加表格最小列宽，并允许单元格中的长代码路径视觉换行；两种视图均包含规则，实际更新效果待用户提供新截图。

代码审查同时发现首版 `.cm-scroller` 的纸面边距规则会匹配表格里的嵌套编辑器。现已将纸面与外边距规则限定为最外层编辑器，并为表格内的行恢复自然对齐。未通过工具操作 Obsidian 验证。

用户随后提供深色截图，反馈标题、列表、代码块的间距及表格前空行问题。截图有编辑光标，本轮按实时预览处理；不改变正文字号、字体栈或全局标题比例。

0.1.2 新增独立间距模块：标题间距按正文字号计算；列表行高为 1.5，列表间距变量从 0.2em 降到 0.06em；代码块在实时预览中通过外层控件 padding 获得段间留白，有源码空行时避免重复叠加。阅读视图也使用同组间距变量。

普通未编辑空行收紧至 0.65 倍正文字号，紧随标题时为 0.45 倍。活动空行、代码、引用、列表、元数据、嵌套单元格编辑器与源码模式均排除。光标进入普通空行后恢复行高，可能发生局部移动，真实光标定位和输入法交互仍需用户验证。保留 Style Settings「保留完整空行高度」退出选项。

表格控件原生留白包含行列拖动控件，未将其清零。主题不更改 Markdown 解析，也不删除源码空行；新增样例包含标题后直接接表格及保留空行两种写法。
