## 自动检查

```sh
npm run check
npm run check:community
npm test
```

- `check`：合并源码、内嵌字体并执行 Stylelint。
- `test:spacing`：42 项间距检查，包含代码块、标题、空行与嵌套编辑器例外。
- `test:appearance`：148 项外观检查，覆盖两种目录结构、浅深色、文字对比度、图标状态、焦点样式和标签范围。

- `test:typography`：154 项浅深色排版检查，覆盖应用字号与字体继承、两种视图的对齐与标题、打印对齐、表格留白、完整颜色值 Callout、混合列表层级与任务框。

- `test:quote-print`：148 项检查，覆盖引用在不同字号、单双段和连续多行中的留白、块高度不变、嵌套编辑器例外，以及固定尺寸 / 百分比宽度 / 超高 / 小图的打印缩放。

- `test:build`：17 项检查，验证构建前后 CSS 语义与顺序、Style Settings 保留、四套字体字节、双语文档及双视图 MathJax 样式。

浏览器测试使用独立 Edge/Chromium 会话，不打开 Obsidian，也不操作个人库。样例只模拟所需 DOM 与原生样式约束；实际编辑器的高度测量、虚拟滚动与插件组合必须另外检查。生成的静态预览带有清楚标记，不能作为实机测试通过的证据。

## 手动检查

使用 `demo-vault` 中的五份原创笔记，在同一字号、宽度和缩放下对比两种视图。覆盖浅深色、窄分栏、引用嵌套、代码反引号编辑、表格长路径与公式；检查中文输入、选区和撤销；最后检查目录展开、滚动、重命名与标签操作。

截图或问题报告应标注版本、视图、字体和缩放。主题最低应用版本声明为 1.13.7，更早版本不作兼容承诺。

0.1.6 的人工回归重点：用 16 / 18 / 24 字号查看长路径，切换「两端对齐正文」，对比导出 PDF；检查 Note / Info / Warning / Danger、折叠与嵌套 Callout，以及三级混合列表的光标和折叠操作。字体不支持中间字重时，H4–H6 的字重差异可能不明显，应同时观察字号和 H6 颜色。

需要生成独立打印样张时运行 `npm run test:quote-print -- --pdf`，输出保存在忽略提交的 `.local/review/`。测试使用带 `viewBox` 与 `foreignObject` 标签的静态 SVG 结构，不执行 Obsidian 或 Mermaid 渲染器。打印最大高度默认 `80vh`（分页环境的页面区域高度比例），可用 CSS 变量 `--qp-mermaid-print-max-height` 调整。

0.1.7 人工回归：核对单行、折行、多行引用的视觉居中；导出边界笔记中的长横向流程图和高纵向流程图，检查首尾节点、箭头与标签。自定义字体、超大页边距和第三方图表插件仍需按实际结果复核。
