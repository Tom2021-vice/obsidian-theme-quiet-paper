# 0.1.1 验证记录

日期：2026-09-17。

## 用户截图反馈与本轮修改

用户已提供首版长截图及普通窗口截图，并确认清空正文字体设置。截图可以确认衬线观感和纸面外观已生效，不能仅凭截图确认具体字体文件及完整双视图一致性。长图在聊天中缩小后显得字小，不据此修改字号。

长表格中的代码路径挤占文字列宽，导致“功能”列频繁换行。0.1.1 增加表格最小列宽，并允许单元格中的长代码路径视觉换行；两种视图均包含规则，实际更新效果待用户提供新截图。

代码审查同时发现首版 `.cm-scroller` 的纸面边距规则会匹配表格里的嵌套编辑器。现已将纸面与外边距规则限定为最外层编辑器，并为表格内的行恢复自然对齐。未通过工具操作 Obsidian 验证。

本轮不改变正文字号、字体栈或全局标题比例。当前视图模式尚未获得用户明确确认，标题到表格的纵向间距暂不作模式专属调整。

## 本机环境与操作记录

只读检查发现本机应用包为 Obsidian 1.13.7，安装器为 1.8.10，本机有 Noto Serif SC。应用版本与安装器版本不同，较新的 CSS 能力采用渐进增强。

开发过程中曾启动本机 Obsidian，指定项目内 `.local/obsidian-profile` 和 `demo-vault`；测试实例加载了该独立配置。没有向个人笔记库执行写入，也未切换个人库主题。用户随后要求不再操作 Obsidian，开发立即转为仅修改项目文件、由用户提供截图的验证方式。

已收到用户提供的首版实际主题截图，未执行编辑交互验证。原先启动的测试窗口由用户自行处理；不再通过工具启动、关闭、切换或控制 Obsidian。

## 已知差异

- 中文字体为候选字体，未确认与原图相同。
- 浏览器两端对齐不等于 Telari 的 Knuth–Plass。
- MathJax 内部排版与 Telari 自研公式引擎不同。
- 实时预览中的活动段落会显露语法；段落与空行的垂直节奏需要真实截图校准。
- 第一阶段没有实现排版增强插件，待具体差异出现后再决定。
